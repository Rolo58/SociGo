# ApprovalFlow 🚀

### Create. Share. Approve. Publish.

ApprovalFlow is a free and open-source client content approval platform built for freelance social media managers and digital marketing agencies.

It simplifies the content approval process by bringing managers and clients together in one organised workspace.

Instead of managing approvals through scattered WhatsApp messages, emails and spreadsheets, ApprovalFlow provides a centralised platform to submit content, collect feedback and track approval statuses.

---

## ✨ Features

- **Dashboard:** View total posts, pending approvals, approved posts and requested revisions.
- **Client Management:** Create and organise multiple client workspaces.
- **Post Management:** Create, edit and manage social media content.
- **Content Approval:** Allow clients to approve posts or request changes.
- **Feedback Management:** Keep client feedback organised in one place.
- **Content Calendar:** View scheduled posts and their approval statuses.
- **Responsive Design:** Access the application from desktop, tablet and mobile browsers.
- **Secure Access:** Role-based permissions for managers and clients.

---

## 🎯 Our Mission

Our mission is to make social media content collaboration simpler, faster and more organised.

ApprovalFlow aims to eliminate unnecessary communication overhead and help freelancers focus on creating quality content instead of chasing approvals.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git
- A Supabase project (if using the hosted Supabase backend)

### Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd approvalflow
```

3. Install dependencies:

```bash
npm install
```

4. Create an environment file:

```bash
cp .env.example .env
```

5. Configure the required environment variables.

6. Start the development server:

```bash
npm run dev
```
